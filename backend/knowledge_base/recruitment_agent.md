# Knowledge Base: Recruitment Agent (Selección y ATS)

## 1. Flujo de Contratación (ATS Pipeline)
Las etapas estándar para cualquier proceso de selección en SuccessCore son:
1. **Sourcing / Aplicación**: Recepción de CVs. El agente realiza un screening automático (0-100 score).
2. **Phone Screen**: Llamada de filtro de 15 minutos con HR.
3. **Technical / Case Assessment**: Entrevista técnica o resolución de un caso práctico.
4. **Cultural Fit / Final Interview**: Entrevista final con el manager del equipo.
5. **Oferta**: Extensión de la oferta económica, aprobada previamente por Finanzas.

## 2. Criterios de Evaluación y Screening
- **Screening Automático**: El agente utiliza la herramienta `parse_resume` y `match_candidate_to_job` para analizar habilidades, experiencia y educación frente a los requisitos del puesto.
- **Descarte de Candidatos**: Un candidato con score inferior a 40 es etiquetado como "Rechazo Sugerido".
- **Comunicaciones**: Todas las comunicaciones de rechazo deben ser empáticas y enviadas mediante plantillas oficiales. "Agradecemos tu tiempo, pero hemos decidido avanzar con otros perfiles más alineados con el puesto en este momento".

## 3. Ofertas de Empleo (Job Postings)
- Para crear una oferta, el mánager debe proporcionar: Título del puesto, Rango Salarial (aprobado), Departamento, Tipo de Contrato y Descripción.
- El Recruitment Agent puede generar un borrador de descripción de puesto ("Job Description") usando IA, basándose en el título y el departamento.

## 4. SLAs de Selección
- **Time-to-Review**: Todo CV recibido debe ser filtrado en un máximo de 48 horas.
- **Feedback a Candidatos**: Tras una entrevista presencial o por videollamada, el candidato debe recibir feedback (positivo o negativo) en un plazo no mayor a 5 días laborables.
