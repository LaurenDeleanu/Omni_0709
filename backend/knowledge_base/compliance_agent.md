# Knowledge Base: Compliance Agent (Legal y Privacidad)

## 1. Protección de Datos (GDPR)
- **Datos Personales Sensibles**: Categorías protegidas (salud, afiliación sindical, religión, datos biométricos) requieren consentimiento explícito. Nunca proceses ni compartas estos datos sin necesidad operativa justificada.
- **Derechos ARCO (Acceso, Rectificación, Cancelación, Oposición)**: Todo empleado tiene derecho a solicitar copia de sus datos. Este proceso tiene un SLA de respuesta obligatoria de 30 días.
- **Retención de Datos**: Los currículos de candidatos no contratados deben borrarse a los 12 meses, a menos que el candidato dé permiso para mantenerlos en la base de datos por más tiempo.

## 2. Canal de Denuncias (Whistleblower)
- SuccessCore cuenta con un canal de denuncias anónimo en `/legal/whistleblower`.
- El agente puede ayudar a redactar o clasificar denuncias sobre: acoso laboral, fraude financiero, discriminación o brechas de seguridad.
- Confidencialidad total: No se rastreará la IP ni el usuario si se envía en modo anónimo.

## 3. Revisión de Contratos y Acuerdos
- Todos los contratos de empleados incluyen una cláusula de confidencialidad (NDA) estándar y otra de no competencia (Non-Compete) de 1 año tras la salida.
- Los periodos de prueba legales estándar son: 6 meses para técnicos titulados, 2 meses para el resto de trabajadores.
- El agente puede ejecutar la herramienta `run_compliance_audit` para revisar que los contratos generados cumplan estas normativas.

## 4. Riesgos Laborales y Prevención (PRL)
- Es obligatorio realizar el curso de PRL y firmar el acuse de recibo de los EPIs (Equipos de Protección Individual) si aplica.
- Los accidentes in itinere (de camino al trabajo) deben reportarse en menos de 24h a RRHH para tramitarlos con la mutua.
