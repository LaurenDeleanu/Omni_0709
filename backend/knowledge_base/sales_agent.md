# Knowledge Base: Sales Agent (CRM y Pipeline)

## 1. Proceso de Ventas B2B
El ciclo de ventas de SuccessCore se compone de las siguientes etapas (Deal Stages):
1. **Lead / Prospecto**: Contacto inicial captado por Marketing o Inbound.
2. **Discovery Call**: Primera llamada para cualificar presupuesto, autoridad, necesidad y tiempo (BANT).
3. **Demo**: Demostración técnica de la plataforma SuccessCore.
4. **Propuesta Comercial**: Envío de presupuesto formal.
5. **Negociación Legal**: Revisión de términos y condiciones (NDA, DPA, SLA).
6. **Closed Won** (Ganado) o **Closed Lost** (Perdido).

## 2. Cualificación (BANT Framework)
- **Budget** (Presupuesto): ¿Tiene el prospecto presupuesto asignado para una herramienta de RRHH?
- **Authority** (Autoridad): ¿Estamos hablando con el decisor (CHRO, CEO)?
- **Need** (Necesidad): ¿Qué dolor están intentando resolver? (ej. alta rotación, nóminas manuales).
- **Timeline** (Tiempo): ¿Cuándo necesitan tener el sistema implementado?

## 3. SLAs de Ventas (Service Level Agreements)
- Todo nuevo Lead inbound debe ser contactado en menos de **2 horas** laborables.
- Las propuestas comerciales deben enviarse en las **24 horas** posteriores a la Demo.
- Si un "Deal" permanece en la etapa "Propuesta" más de 14 días sin actividad, debe ser marcado como "At Risk" (En riesgo).

## 4. Estructura de Comisiones (Variable)
- Los ejecutivos de cuentas (AEs) comisionan un 10% del ARR (Annual Recurring Revenue) generado en cada cierre.
- Los cierres de contratos multianuales pagan la comisión del primer año de forma inmediata, y un 2% adicional en renovaciones.
- El agente puede interactuar con el módulo de CRM para actualizar las etapas del deal o crear tareas de seguimiento para el vendedor.
